# 2026-10-30_image-editor-polish: допиливаем image-editor

**Created:** 2026-10-30T18:47:14+03:00

## Scope

Доработка `packages/image-editor` по девяти пунктам бэклога. Всё внутри пакета, без новых зависимостей; интеграция с `dsh-attach-editor` не меняется (тестиды `editor-canvas`, `editor-tool-marker`, `editor-color-picker`, `editor-width-picker`, `editor-undo`, `editor-save` остаются стабильными).

**Новые инструменты:**
1. **Step** — скобочная нумерация: красный круг с белой границей и тенью, белая цифра внутри. При удалении любого Step остальные перенумеровываются. **Правка 2026-10-31:** минимальный размер круга (чтобы цифра читалась при шрифте 18px); круг можно ставить кликом без протяжки — протяжка остаётся, но результат не меньше минимального; толщина границы уменьшена в 2 раза → дефолт 4px.
2. **Speech balloon** — работает как текст, оформлен как комиксный баллон; кончик баллона в точке клика инструментом.
3. **Leader (выноска)** — работает как стрелка с текстом: толстая точка в первом клике, линия, на конце горизонтальная полка, над полкой текст.

**Выделение и свойства:**
4. Смена цвета/толщины при невыпустом выборе применяет цвет и толщину к выбранному элементу (включая множественный выбор) — и, как сейчас, к дефолтам инструмента.
5. Для стрелки и выноски при выделении вместо bbox показывать 2 точки на концах (перемещение начала/конца) и квадрат в середине для перетаскивания всего элемента.
6. Для bbox выбранного элемента: квадрат перетаскивания в середине; квадраты изменения размера → кружки; белая окантовка квадратов и кружков; курсоры по узлам: перетаскивание `move`, вращение — SVG-курсор rotate, угловые — `pointer`, вертикальные/горизонтальные — `col-resize`/`row-resize`.

**Мелкие правки:**
7. `ctrl+z` — undo (см. Approach: почти наверняка уже реализовано, пункт сводится к проверке).
8. Толщина линии по умолчанию → 8px (фактически текущий дефолт 4px, а не 2px — «неюзабельность» ощущается на тонких штрихах; решение: дефолт 8px для всех чертящих инструментов кроме highlighter, который остаётся 14px). **Правка 2026-10-31:** для стрелки, бокса (rect) и выноски (leader) дефолтная толщина всё-таки 4px; marker остаётся 8px, highlighter — 14px, step — 4px (граница круга).
9. Убрать «px» из видимых подписей (попаны толщины и размера шрифта, плавающие кнопки `editor-text-size`/`editor-shape-size`); в тултипах (`title`/`aria`) px остаётся.

**Правка, волна 2 (2026-10-31):**
10. **Leader — полка и текст:** полка сдвинута с центра на кончик линии — начинается в кончике линии и идёт горизонтально от shaft в сторону протяжки; длина полки фиксированная, вдвое длиннее текущей; текст размещается на кончике полки (его дальний конец у кончика полки, зеркально для протяжки влево), над полкой; многострочный текст вертикально центрируется относительно линии полки.
11. **Белая обводка + тень у arrow/rect/leader** — как у Step, но толщина обводки 2px (белая полоса 2px вокруг цветной обводки формы + тень). Текст и speech не трогаем.
12. **Стрелка:** кончик стрелки указывает на начало клика — головка рисуется в `from` (точка pointerdown), shaft тянется от протянутого уголка к ней.

**Out of scope:** новые зависимости, изменения в `dsh-attach-editor`, изменение contract'а контроллера кроме добавления новых инструментов в union.

## Approach

- Пакет Canvas 2D: `scene.ts` (модель), `tools.ts` (жесты), `transform.ts` (bbox-математика + хэндлы), `hit.ts`, `render.ts` (отрисовка + оверлей выделения), `input.ts` (жесты ввода), `editor.ts` (DOM тулбар + контроллер). Новые инструменты добавляются по существующему образцу: `EditorTool` union → вариант `Shape` → `toolRegistry` → `EDITOR_TOOLS` → `TOOL_DEFAULT_COLORS/WIDTHS` (exhaustive Record) → `TOOL_ICONS` → ветка в `drawShape` → ветка в `shapeHitInLocal`.
- **Step:** цифра вычисляется при рендере из порядка Step-элементов в сцене (не хранится), поэтому удаление перенумеровывает остальные автоматически. Круг занимает bbox; цифра рисуется белым, размер пропорционален минимальной стороне bbox — resize масштабирует круг и цифру. **Правка:** минимальный диаметр круга = 36px world units (цифра рисуется шрифтом ≈ диаметр/2 → при минимуме 18px, отсюда и «отталкиваясь от шрифта 18px»); клик без протяжки коммитит круг минимального диаметра по центру клика; протяжка остаётся, но результат клампится минимумом (растягивание больше минимума работает как сейчас). Толщина границы = `shape.width`, дефолт step → 4px (было 8).
- **Speech balloon:** эллипс по bbox + хвост (кончик) к якорю — точке клика; якорь хранится в bbox-local координатах (прецедент — `from`/`to` стрелки), двигается вместе с элементом. Текст внутри как у `TextShape` (`fontSize`); resize растягивает эллипс.
- **Leader:** сегмент `from`/`to` (прецедент `ArrowShape`) + текст: толстая точка в `from`, линия, горизонтальная полка в `to`, текст над полкой. Resize растягивает как стрелка. **Правка волна 2:** полка закреплена в кончике линии (`to`) и идёт горизонтально от shaft в сторону протяжки (знак `to.x − from.x`, при dx=0 — вправо); длина полки — фиксированная константа (вдвое больше текущего текста-зависимого span; точное значение — из research на формуле `leaderShelfHalf`); текст якорится на дальнем кончике полки (right-aligned для протяжки вправо, зеркально влево), над полкой; для многострочного текста блок центрируется по вертикали относительно линии полки. Хит-полоса labels обновляется под новую полку/текст.
- **П.4:** контроллер `setColor`/`setWidth` при непустом выборе коммитит `replaceShape` для выбранных форм через `commit()` (undo-безопасно), плюс текущее поведение по дефолтам инструмента.
- **П.5:** для kinds `arrow`/`leader` оверлей выделения — вместо bbox и 8 хэндлов: две точки-эндпоинты + центральный квадрат перетаскивания; новые хэндл-виды в `hitHandle`/`handleSlots` и роутинг драга в `input.ts`; вращение для стрелки/выноски убирается.
- **Обводка+тень (волна 2):** для `arrow`/`rect`/`leader` в `drawShape` — белый halo-pass под цветной обводкой: белая линия толщиной `shape.width + 2×2` (обводка 2px с каждой стороны) + тень по образцу `drawStep` (тот же shadow recipe); затем обычный цветной pass. `text`/`speech`/`step` без изменений (step уже имеет кольцо и тень). Hit-геометрия не меняется (halo визуальный).
- **Стрелка (волна 2):** головка рисуется в `from` (начало клика), shaft идёт от протянутого уголка к `from`; эндпоинт-хэндлы `end-start`/`end-end` и `editEndpoint` остаются как есть (from/to семантика та же, меняется только ориентация головки в render).
- **Step цифра (волна 3):** цвет цифры авто-контрастный по luminance заливки бейджа: светлая/белая заливка → тёмная цифра (`#1a1a1a`), тёмная → белая. Кольцо/тень step не меняются.
- **Leader полка+текст (волна 3):** фиксированная длина полки укорачивается в 2 раза: 86 → 43px world; однострочный текст выноски центрируется по вертикали относительно линии полки (как многострочный — строка пересикает линию полки), многострочный остаётся центрированным; свисание длинного текста за полку допускается (длина фиксированная). Толстая зелёная черта на скриншоте — аннотация длины полки, отдельная фича не вводится.
- **Leader текст — сдвиг от полки (волна 4):** подпись сдвигается за дальний кончик полки с отступом `LEADER_LABEL_GAP = 12` world px: для протяжки вправо левый край текста = кончик полки + 12 (left-aligned), зеркально для влево — правый край = начало полки − 12 (right-aligned). Вертикаль не меняется — блок центрирован на линии полки (этот вариант в моке подтверждён). Текст больше не перекрывает штрих полки; свисание теперь за кончик полки, не за её начало. Хит-полоса полосы extends в сторону текста: x-band покрывает полку + отступ + ширину текста (для лево-полки — зеркально).
- **П.6:** хэндлы bbox: 8 слотов → кружки с белой окантовкой, новый центральный квадрат перетаскивания, rotate-круг с белой окантовкой; курсоры задаются на canvas CSS-курсором по hover-узлу (включая кастомный SVG cursor для rotate: `cursor: url(data:…) 8 8, grab`).
- **П.7:** `Ctrl/Cmd+Z` уже реализован в `input.ts` — пункт = verify (unit/e2e), без кода, если подтвердится.
- **П.8:** `DEFAULT_WIDTH` и `TOOL_DEFAULT_WIDTHS` чертящих инструментов → 8; highlighter 14 остаётся; `WIDTH_PRESETS` не меняется (8 уже есть). **Правка 2026-10-31:** `TOOL_DEFAULT_WIDTHS` для arrow/rect/leader → 4 (step → 4); `DEFAULT_WIDTH` = 8 остаётся для marker; highlighter 14; толщина leader-точки = width×1.5 → 6px, стрелка/бокс штрих 4px.
- **П.9:** видимые подписи без px: `${px}px` → `${px}` в попапах толщины и шрифта, `` `${fontSize} px` `` → `${fontSize}` на плавающих кнопках; тултипы не трогаем.
- TDD: красный тест → реализация → refactor + commit на каждый stage; тесты `index.test.ts` ( Exact `EDITOR_TOOLS`) и `scene.test.ts` обновляются вместе с union/дефолтами.

## Constraints

- `packages/image-editor` dependency-free (только devDeps из catalog); никаких `pnpm add`.
- Consumer `dsh-attach-editor` импортирует только `mountImageEditor` и в e2e ассертирует существующие testids — существующие id стабильны, новые по конвенции `editor-tool-<name>`.
- `index.test.ts` ассертирует точный массив `EDITOR_TOOLS` и значения констант; `scene.test.ts` — порядок ключей color/width.
- Сцена immutable (frozen scenes, snapshot-undo через `commit()`); live-preview не толкает history.
- Команды: `pnpm test` (vitest unit), `pnpm test:e2e` (build + playwright), `pnpm typecheck` из директории пакета; временное — в `.tmp/`.
