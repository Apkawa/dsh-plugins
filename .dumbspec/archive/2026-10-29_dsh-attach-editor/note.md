# список замечаний

1. [x] перемещение холста средней кнопкой мыши слишком быстрое и несогласованное. надо со скоростью движения мыши, типа схватил и потащил.
2. [x] панель  с кнопками выровнять по центру
3. [x] если выбрать нарисованный элемент то при клике на холст или использовании другого инструмента выделение не сбрасывается. надо чтобы сбрасывалось.
4. [x] нужен инструмент select (обычно просто указатель мыши). он позволяет выбрать и менять параметры элементов. выбор в том числе и множественный, протягиванием (выбрал несколько - удалил или переместил)
5. [x] при других инструментах выбрать другие элементы можно только при зажатой клавише Ctrl. Это позволит рисовать поверх других нарисованных элементов
6. [x] текст
  - многострочный текст, ctrl+enter - новая строка
  - добавить возможность редактирования текста, даблкликом по выбранному тексту
  - так же размер текста можно поменять во время редактирования, сверху над полем во время редактирования появляется кнопка с текущим размером текста. при клике появляется выбор размеров. выбранный размер применяется ко всему тексту во время редактирования. так же эта кнопка размера появляется при выборе элемента текста, над текстом. (наверное можно менять размер текста и при нескольких выбранных элементов текста)
  - добавить возможность менять размер текста увеличением прямоугольника выделения
7. [x] перерисовать иконку отмены она выглядит как знак U turn повернутый по часовой стрелке  (стрелка идет справа и возвращается налево, стрелка наверху)
8. [x] инструмент стрелка, треугольник нарисованной стрелки подвинуть вперед, а то линия торчит.
9. [x] инструмент выделение, при выборе другого цвета выделение все равно желтое.
10. [x] для каждого инструмента запоминать выбор цвета, у каждого инструмента свой цвет, при переключении инструментов переключать цвет. у инструментов есть цвет по умолчанию который в последствии можно поменять, желтый у выделения, красный у остальных
11. [x] если выбрать элемент с ctrl не используя select, то при попытке поменять размер или переместить выделение сбрасывается (конфликт с пп 3). Надо иметь возможность вращать, перемещать и менять размер.
12. [x] если повернуть элемент, то изменение размера становится очень непредсказуемым, т.е. вторую точку относительно которой меняем размер тоже надо поворачивать (или как там правильно делать, хз).
13. [x] продолжая 10 - запоминать выбор толщины линии
14. [x] у инструмента Highlighter (текстовыделитель) не работает выбор толщины линии, по умолчанию делать толстым 14px.
