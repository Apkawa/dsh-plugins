# mvp

## Редактор изображений

1) (ванильная схема) Я пишу сообщение агенту, вставляю аттач (из файла или буфера). при клике на аттач открывается предпросмотр изображения.
2) прямо над изображением добавить кнопку редактирования
3) при нажатии на кнопку изображение улетает в редактор в правом сайдбаре (в вкладке сайдбара) (пример работы с сайдбаром в packages/dsh-global-queue )
4) минимальный набор для редактора
 - маркер
 - текстовыделитель (цвет по умолчанию желтый)
 - стрелочка
 - прямоугольник
 - текст
 - undo (ctrl+z)
 - зум колесиком мышки

цвет по умолчанию красный
цвет и толщину можно быстро выбрать из предустановленных вариантов
стрелочку, прямоугольник, текст можно отредактировать после отрисовки (поворот, растяжение, перемещение)

Редактор надо сделать standalone компонент с возможностью запуска отдельно, в packages/image-editor (сделать тестовую страницу чтобы его потыкать), и использовать в плагине, подвязать все необходимые хуки и пропсы,
редактор не должен быть связан с dsh зависимостями

5) сохраняем, и аттач заменяется на новый
